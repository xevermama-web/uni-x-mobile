# Uni-X — University Management System

Uni-X is a modern, secure, and user-friendly university management system designed to digitize and simplify academic and administrative activities.

## Features

* Role-based authentication and access control
* Student management
* Faculty management
* Department and batch management
* Attendance tracking and analytics
* Class routine and timetable management
* Course materials and file management
* Study groups and real-time chat
* Real-time notifications
* University notices and announcements
* Responsive and mobile-friendly interface
* Secure database with role-based permissions

## User Roles

| Role          | Access                                                       |
| ------------- | ------------------------------------------------------------ |
| **Admin**     | Full system management                                       |
| **Moderator** | Academic and group-related management                        |
| **Faculty**   | Attendance, materials, groups, and academic activities       |
| **Student**   | Attendance, routine, materials, groups, notices, and profile |

## Technology Stack

* **Frontend:** React, TypeScript
* **Backend:** Supabase
* **Database:** PostgreSQL
* **Authentication:** Supabase Auth
* **Storage:** Supabase Storage
* **Deployment:** Vercel / Netlify
* **Version Control:** Git & GitHub

## Core Modules

### Attendance

Faculty can manage student attendance, while students can view their attendance records and percentage. Admins and moderators can access department-level attendance analytics.

### Routine and Timetable

Admins can create and update class routines. Students can view their schedules and identify ongoing or completed classes.

### Study Groups

Students and faculty can participate in group-based communication with real-time messaging and role-based permissions.

### Materials

Faculty, admins, and moderators can upload academic materials for specific groups. Students can access and download uploaded files.

### Notifications

Users receive notifications for important updates such as notices, routine changes, new materials, study groups, and attendance-related alerts.

## Security

Uni-X uses Supabase Authentication, PostgreSQL Row Level Security (RLS), and role-based access control to protect user data and prevent unauthorized operations.

## Responsive Design

The interface is designed to provide a consistent experience across desktop, tablet, and mobile devices while maintaining the core functionality of the system.

## Project Goal

The goal of Uni-X is to provide a centralized digital platform that makes university academic management more efficient, accessible, and organized for students, faculty, moderators, and administrators.

## Development

Uni-X is developed as an academic software project with a focus on modern web technologies, secure backend architecture, real-time functionality, and practical university management requirements.
